Zap Funds — Blog manager

Publish and delete blog posts on zapfunds.com.au. Changes go live in about 1–2 minutes while GitHub rebuilds the site.

GitHub access

Create one at GitHub → Settings → Developer settings → Fine-grained tokens: repository access sofund only, permission Contents: Read and write.

Publish a new post

Your text is published exactly as written: blank lines split paragraphs, ## Heading lines become section headings, - item lines become bullet lists, **bold** becomes bold. Nothing is rewritten.
