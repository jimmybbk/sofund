Quickstart

The Hue Write API allows you to programmatically humanize AI-generated text. This endpoint is available exclusively for Max plan subscribers.

POSThttps://huewrite.com/api/v1/humanize
  1. 1

    Create a key

    On the Developer page. It's shown once, so store it as HUEWRITE_API_KEY.

  2. 2

    Send your text

    POST a JSON body with text and, optionally, a tone and model.

  3. 3

    Read the stream

    The humanized text streams back as text/plain.

cURL
curl -X POST https://huewrite.com/api/v1/humanize \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $HUEWRITE_API_KEY" \
  -d '{
    "text": "Your AI-generated text here",
    "tone": "standard",
    "modelVersion": "v4beta"
  }'

Authentication

Authenticate every request with your secret API key, sent as a Bearer token.

Authorization header
Authorization: Bearer hue_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  • Create and revoke keys on the Developer page. The full key is shown only once, when you create it.
  • Keys begin with hue_ and expire 90 days after creation. You can hold up to 10 at a time.
  • Call the API from your server. Never ship a key in client-side code or commit it to a repository.

Request Body

The API accepts JSON requests and returns streaming text responses.

ParameterTypeDescription
textRequiredstringThe text to humanize: at least 10 characters, and up to 3,000 words per request on the Max plan.
toneOptionalstringWriting style. One of standard, academic, professional, friendly, formal, casual or creative.Default: standard
modelVersionOptionalstringHumanization model: v4beta, v3.5 or v3. Newer models enabled for your account are listed, with their value, in the playground on the Developer page.Default: v4beta
ultraModeOptionalbooleanEnable Ultra Mode for a more thorough humanization pass.Default: false
rewriteLevelOptionalstringHow freely the text is rewritten: quality stays closest to the original wording, balanced is the recommended middle and max rewrites the most.Default: balanced
polishOptionalbooleanRun a final copy-edit pass over the result. Set to false to skip it.Default: true
isRehumanizationOptionalbooleanHumanize the same text again for a different result, without using credits. The text must match an earlier request exactly; the Max plan allows 3 per text.Default: false
teamIdOptionalstringRun the request in a team workspace, drawing credits from the team owner. Required when your API access comes from a team rather than your own Max plan.

Example request body

JSON
{
  "text": "Your AI-generated text here",
  "tone": "standard",
  "modelVersion": "v4beta",
  "ultraMode": false,
  "polish": true
}

Response

On success the humanized text streams back chunk by chunk.

200 OKtext/plain; charset=utf-8
  • Read the body incrementally to show progress, or wait for it to finish for the whole text.
  • Paragraphs are separated by a blank line.
  • Credits are charged by the word, the same as in the web app.

Errors

Errors return JSON with a stable error code and a human-readable message.

JSON
{
  "error": "rate_limit_exceeded",
  "message": "API rate limit exceeded. Please slow down.",
  "resetAt": "2026-06-20T12:00:00.000Z"
}
StatusCodeMeaning
400validation_errorThe body is invalid, e.g. the text is missing or too short.
400 / 403model_unavailableThe model is retired or isn't enabled for your account.
400rehumanization_invalidisRehumanization was set, but the text doesn't match an earlier request.
401unauthorizedThe key is missing, malformed, revoked or expired, or the account no longer has API access.
403insufficient_creditsNot enough word credits left for this text.
403rehumanization_limit_exceededThis text has used all of its rehumanizations.
403permission_deniedYour team owner has turned this option off for your account.
429rate_limit_exceededMore than 30 requests in a minute across your account. Wait for the time in the Retry-After header.
429concurrent_limit_exceededToo many requests running at once. Wait for one to finish.
429member_credit_limit_exceededYou've used your monthly word limit in this team.
500internal_errorSomething went wrong on our side. Retry with backoff.
504processing_timeoutThe request took too long to process. Retry, or send shorter text.

Rate-limited responses include Retry-After, X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset headers.
